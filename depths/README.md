# DEPTHS OF THE UNSEEN

A first-person Backrooms survival horror game for the browser, built from the
*Depths of the Unseen* complete design document (version 1.0). An overnight
maintenance crew follows a distress call from a coworker who vanished eleven
years ago into an impossible service corridor. An instant camera exposes what
hides beneath ordinary rooms.

Work in progress. See [STATUS.md](STATUS.md) for what is playable now.

```bash
cd depths
npm install
npm run dev        # http://localhost:5190
```

Everything (rooms, textures, creatures, voices, sounds and music) is generated
in code at load time.
